# Recent Factory Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the four latest supplied factory and equipment photos on the factory and equipment pages without changing company, product, contact, or visual-design content.

**Architecture:** Copy source photographs into `public/images` under descriptive names. Extend the existing `PhotoEvidence` usage with a responsive gallery on the factory page and a paired view on the equipment page; every image source is generated by `withBase()` for GitHub Pages.

**Tech Stack:** Astro static site, scoped Astro CSS, Node test runner.

## Global Constraints

- Keep company name, phone, WeChat, product content and the gray-blue visual system unchanged.
- Do not make claims about models, output, certification or manufacturing capability based on a photograph.
- The image with visible machine-manufacturer contact text is only a secondary equipment view and must not be labelled as company contact information.
- New public image URLs must render under `/WFB/images/` after build.
