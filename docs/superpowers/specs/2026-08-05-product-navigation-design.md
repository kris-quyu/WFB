# 产品导航合并设计

## 目标

将页头中的“产品 A / 产品 B / 产品 C”三个入口合并为一个“产品介绍”，减少传统制造企业官网顶部导航的拥挤感，并让访客先看到三类产品的总览。

## 交互

- “产品介绍”指向首页的 `#products` 产品区域。
- 产品总览仍展示产品 A、B、C 三张卡片。
- 三个产品详情页及卡片链接继续保留，用于展示参数、采购事项和 SEO/GEO 收录。
- 桌面端与移动端共用同一份导航数据。

## 验收标准

- 顶部导航只出现一个“产品介绍”。
- 顶部导航不再出现“产品 A / 产品 B / 产品 C”。
- 点击“产品介绍”进入首页产品区域。
- 三个产品详情页仍能正常构建和访问。
- 自动测试、Astro 检查与静态构建通过。
