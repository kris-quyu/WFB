# 首页单首屏设计

## 目标

将首页从栏目内容集合收缩为一个清晰的企业入口页。首页只展示真实生产现场主视觉，用户继续向下滚动时直接进入全站页脚；产品、工厂、设备、应用和知识内容继续保留在各自独立页面。

## 页面结构

1. 现有顶部资料状态栏与主导航。
2. 单个沉浸式首屏：真实生产线照片、企业定位标题、简短说明、产品介绍按钮、联系/询价按钮和真实照片说明。
3. 全站页脚。

首页不再包含能力证据、应用场景、FAQ、资料状态说明、询价面板或其他栏目摘要。

## 滚动行为

- 首屏最小高度为当前可视窗口扣除站点页头后的高度。
- 首页启用纵向滚动吸附：首屏为第一个吸附点，页脚为第二个吸附点。
- 使用 `scroll-snap-type: y proximity`，避免强制吸附妨碍键盘导航或移动设备自然滚动。
- 开启平滑滚动；尊重 `prefers-reduced-motion`，减少动态偏好的用户不启用平滑动画。
- 删除旧的首页 `#products` 锚点；历史地址即使携带该无效片段，也只显示首页顶部，不再跳到不存在的栏目。

## 视觉延续

- 主色保持灰蓝 `#405066` 与暖白 `#F2F2F2`。
- 首屏继续使用用户提供的真实生产线照片。
- 红色仅用于主要行动按钮。
- 页脚保持现有全站信息架构，不在首页重复其联系方式和快速导航内容。

## 验收标准

- 首页源代码不再引入能力卡片、应用数据、FAQ、占位说明或联系面板。
- 首页渲染后只有一个主内容 section，随后直接进入 footer。
- 首屏按钮仍可进入 `/products/`，第二按钮进入独立联系目标或暂时采用明确的联系路径，不链接不存在的首页锚点。
- 桌面与移动端没有横向溢出。
- Astro 构建、类型检查、现有 SEO/GEO 测试和新增首页结构测试全部通过。
