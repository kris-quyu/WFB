# 首页单首屏与全站配色设计

## 目标

将首页从栏目内容集合收缩为清晰的企业入口页。首页只展示真实生产现场主视觉，向下滚动直接进入全站页脚。产品、工厂、设备、应用、FAQ、资料状态和询价内容继续保留在各自独立页面。

## 首页结构

1. 顶部资料状态栏与主导航。
2. 单个沉浸式首屏：真实生产线照片、企业定位标题、简短说明、产品介绍按钮、联系/询价按钮和真实照片说明。
3. 全站页脚。

首页不再包含能力证据、应用场景、FAQ、资料状态说明、询价面板或其他栏目摘要。

## 其他内容的归属

- 产品参数与采购事项：`/products/` 及各产品详情页。
- 工厂资料：`/factory/`。
- 生产设备：`/equipment/`。
- 质量流程：`/quality/`。
- 应用场景：`/applications/`。
- FAQ 与知识文章：`/knowledge/`。
- 资料状态说明与询价面板：仅放在需要核实资料或促成询价的内页，不在首页重复。

## 滚动行为

- 全站采用自然、连续的纵向滚动。
- 全局开启 `scroll-behavior: smooth`，不使用强制整屏吸附或滚轮劫持。
- 尊重 `prefers-reduced-motion`；减少动态偏好的用户关闭平滑滚动。
- 首页首屏最小高度按可视窗口扣除页头后的剩余高度计算，使首屏和页脚衔接紧凑。
- 删除旧的首页 `#products` 锚点和所有指向不存在首页锚点的链接。

## 全站视觉系统

- 主色灰蓝：`#405066`。
- 深色灰蓝：`#303D50`，用于页脚、顶部状态栏和深色内容区。
- 暖白：`#F2F2F2`，用于页面背景与浅色区块。
- 纯白：`#FFFFFF`，用于卡片与正文对比。
- 强调红：`#B8322A`，只用于主要按钮、当前导航和筛选状态。
- 全站移除绿色与黄色主色，包括页头、页脚、按钮、表格、卡片链接、主题色元数据及组件中的绿色调文字。
- 首屏继续使用用户提供的真实生产线照片；不虚构产品照片、产能、设备型号或质量数据。

## 联系/询价按钮

首页第二按钮不再指向首页 `#contact`。在企业联系方式尚未核实前，链接到产品介绍页的询价准备区域；待企业电话或邮箱确认后，再改为真实联系方式。

## 验收标准

- 首页源代码不再引入能力卡片、应用数据、FAQ、占位说明或联系面板。
- 首页渲染后只有一个主内容 section，随后直接进入 footer。
- 应用、FAQ、资料状态和询价内容在相应独立页面仍可访问。
- 全站 CSS 与主题元数据不再包含原绿色调色板。
- 全站滚动连续，不存在强制吸附或滚轮劫持。
- 桌面与移动端没有横向溢出。
- Astro 构建、类型检查、SEO/GEO 测试及新增首页结构和配色测试全部通过。
